# MOM- (Minutes of Meeting AI Agent)

An enterprise-grade, multi-agent AI system for real-time and recorded meeting transcription, speaker diarization, executive summary synthesis, SMART action item extraction, and corporate PDF generation.

## 🚀 Key Features
- **Parallel 10-Agent Swarm**: Specialized agents for Summary, Action Items, Decisions, Requirements, Risks & Blockers, Sentiment, Discussion Topics, Deadlines, Questions, and Follow-ups.
- **Hierarchical Map-Reduce Chapter Engine**: Processes 1-hour+ long recordings without context clipping.
- **Executive Action Item Reframer**: Converts conversational speech into boardroom-ready formal business tasks.
- **Single Source of Truth (SSOT)**: 100% synchronization across Streamlit UI, MongoDB memory, and ReportLab corporate PDFs.
